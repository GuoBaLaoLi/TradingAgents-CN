# 2. 安装数据库

## 安装 PostgreSQL

- 添加 PostgreSQL 官方仓库并安装 PostgreSQL 16：
```bash
# 添加 PostgreSQL 官方仓库
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
echo "deb http://apt.postgresql.org/pub/repos/apt/ $(lsb_release -cs)-pgdg main" | sudo tee /etc/apt/sources.list.d/pgdg.list

# 更新并安装 PostgreSQL 16
sudo apt update
sudo apt install -y postgresql-16 postgresql-client-16
```

- 启动 PostgreSQL 服务：
```bash
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

- 创建数据库和用户：
```bash
# 以 postgres 用户身份登录
sudo -u postgres psql

# 在 psql 提示符下执行以下命令：
CREATE DATABASE tradingagents;
CREATE USER tradinguser WITH PASSWORD 'your_postgres_password';
GRANT ALL PRIVILEGES ON DATABASE tradingagents TO tradinguser;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO tradinguser;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO tradinguser;

# 退出 psql
\q
```

> **注意**：请将 `your_postgres_password` 替换为强密码，并记录下来，后续配置环境变量时需要使用。

## 安装 Redis
```bash
sudo apt update
sudo apt install -y redis-server
sudo systemctl start redis
sudo systemctl enable redis
sudo systemctl restart redis
```

- 设置密码（参考docker-compose.hub.nginx.yml配置）
- 编辑配置文件: /etc/redis/redis.conf
- 添加: requirepass tradingagents123

# 3. 配置后端环境
## 3.1 创建 Python 虚拟环境
```bash
python -m venv venv
source venv/bin/activate
```


## 3.2 安装 Python 依赖
```bash
# 配置清华镜像
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
# 验证配置
pip config list
# 确保在 app 目录下且虚拟环境已激活
pip install -r requirements.txt 
```



## 3.3 配置环境变量
- 创建 .env 文件：
```bash
cp .env.example .env
```
- 编辑 .env 文件，配置以下关键参数：
```yml
# 数据库配置（PostgreSQL）
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=tradingagents
POSTGRES_USER=tradinguser
POSTGRES_PASSWORD=your_postgres_password

# Redis 缓存
REDIS_URL=redis://:tradingagents123@localhost:6379/0

# API 配置
API_BASE_URL=http://localhost:8000
CORS_ORIGINS=["http://localhost:3000"]

# LLM 配置（根据需要配置）
OPENAI_API_KEY=your_openai_key
DEEPSEEK_API_KEY=your_deepseek_key
SILICONFLOW_API_KEY=your_siliconflow_key

# 其他配置
DEBUG=true
LOG_LEVEL=INFO
```
```markdown
数据库账号密码说明：
• PostgreSQL：用户名 tradinguser，密码 your_postgres_password（安装时设置的），数据库 tradingagents
• Redis：密码 tradingagents123，无用户名（使用空用户名）
```
```markdown
**重要提示：**
• 生产环境请务必修改默认密码
• PostgreSQL 密码是安装步骤中设置的密码
• Redis 连接字符串中的 :tradingagents123 表示空用户名加密码的格式
```
- 编辑 .env 文件，配置以下关键参数：
```yml
# 数据库配置（参考docker-compose.hub.nginx.yml中的配置）

# 其他配置

LOG_LEVEL=INFO
```
```markdown
数据库账号密码说明：
• MongoDB：用户名 admin，密码 tradingagents123，数据库 tradingagents
• Redis：密码 tradingagents123，无用户名（使用空用户名）
• 这些账号密码配置与 docker-compose.hub.nginx.yml 中的配置保持一致
```
```markdown
**重要提示：**
• 生产环境请务必修改默认密码
• MongoDB连接字符串中的 authSource=admin 参数表示在admin数据库中进行身份验证
• Redis连接字符串中的 :tradingagents123 表示空用户名加密码的格式
```

# 5. 初始化数据库

## 5.1 启动 PostgreSQL 和 Redis
- 确保数据库服务正在运行：
```bash
# 检查 PostgreSQL
sudo systemctl status postgresql  # Linux
brew services list | grep postgresql  # macOS

# 检查 Redis
sudo systemctl status redis  # Linux
brew services list | grep redis  # macOS
```

## 5.2 创建数据库表和初始数据

- 创建 PostgreSQL 表结构：
```bash
# 执行表结构创建脚本（需要先设置密码环境变量）
export PGPASSWORD=your_postgres_password
psql -U tradinguser -d tradingagents -f scripts/migrations/create_postgresql_tables.sql

# 或者不使用环境变量，直接在命令中指定密码
PGPASSWORD=your_postgres_password psql -U tradinguser -d tradingagents -f scripts/migrations/create_postgresql_tables.sql
```

- 表结构说明：
  - `stock_basic_info` - 股票基础信息表
  - `stock_daily_quotes` - 历史K线数据表
  - `market_quotes` - 实时行情表
  - `stock_financial_data` - 财务数据表
  - `users` - 用户表
  - `token_usage` - Token 使用统计表
  - `system_config` - 系统配置表
  - `model_config` - 模型配置表

```markdown
- 重要提示：`scripts/migrations/create_postgresql_tables.sql` 脚本必须执行，它会：
    • 创建所有必要的数据库表
    • 为关键字段创建索引以提高查询性能
    • 设置表之间的约束关系
- 如果不执行此步骤，系统将无法正常运行。
```

# 9. 故障排除
## 9.1 常见问题
### 后端启动失败
- 问题：端口被占用
```bash
# 查找占用 8000 端口的进程
netstat -ano | findstr :8000  # Windows
lsof -i :8000  # macOS/Linux

# 终止进程
taskkill /PID <pid> /F  # Windows
kill -9 <pid># macOS/Linux
```

- 问题：依赖安装失败
```bash
# 升级 pip
python -m pip install --upgrade pip

# 清理缓存
pip cache purge

# 重新安装
pip install -r requirements.txt --force-reinstall
```

### 前端构建失败
- 问题：Node.js 版本不兼容
```bash
# 检查 Node.js 版本
node --version

# 使用 nvm 切换版本
nvm use 18

# 清理 node_modules
rm -rf node_modules package-lock.json
yarn install
```

- 问题：内存不足
```bash
# 增加 Node.js 内存限制
export NODE_OPTIONS="--max-old-space-size=4096"

# 或使用 npm
npm run dev -- --max-old-space-size=4096
```

### 数据库连接失败
- 问题：PostgreSQL 连接失败
```bash
# 检查 PostgreSQL 状态
sudo systemctl status postgresql

# 重启 PostgreSQL
sudo systemctl restart postgresql

# 测试连接
PGPASSWORD=your_postgres_password psql -U tradinguser -d tradingagents -c "SELECT 1"
```

- 问题：Redis 连接失败
```bash
# 检查 Redis 状态
sudo systemctl status redis

# 重启 Redis
sudo systemctl restart redis

# 测试连接
redis-cli ping
```

- 问题：后端启动时报错无法连接 PostgreSQL
1. 检查 PostgreSQL 是否正在运行：
```bash
sudo systemctl status postgresql
```
2. 检查 .env 文件中的 POSTGRES_* 配置是否正确
3. 检查防火墙是否阻止了 5432 端口

- 问题：登录时报错 "系统配置缺失" 或 API 返回 404 错误
1. 检查 PostgreSQL 表结构是否已创建（最常见问题）：
```bash
# 激活虚拟环境后，执行表结构创建脚本
PGPASSWORD=your_postgres_password psql -U tradinguser -d tradingagents -f scripts/migrations/create_postgresql_tables.sql

# 验证表是否创建成功
PGPASSWORD=your_postgres_password psql -U tradinguser - tradingagents -c "\dt"

# 验证初始化是否成功：
curl http://localhost:8000/api/system/config
# 应该返回系统配置信息，而不是404错误
```

### 默认用户无法登录
- 问题：使用 admin/admin123 无法登录
```bash
# 检查 PostgreSQL 表结构是否已创建
PGPASSWORD=your_postgres_password psql -U tradinguser -d tradingagents -c "SELECT * FROM users WHERE username='admin';"

# 如果用户不存在，需要手动插入（注意：密码需要SHA256哈希）
# 默认密码 admin123 的 SHA256 哈希值为：
# 240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9
PGPASSWORD=your_postgres_password psql -U tradinguser -d tradingagents -c \
  "INSERT INTO users (username, email, hashed_password, is_admin) VALUES ('admin', 'admin@tradingagents.cn', '240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9', true);"

# 检查密码是否正确：默认密码是 admin123
```
